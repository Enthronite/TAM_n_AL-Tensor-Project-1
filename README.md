Compilation Using Microsoft Visual C++
---------------------------------------
Since we have created two seperate test files, follow these instructions for 
how to run the program in each one of them.

1. Habach_test.cpp

-Open a Developer Command Prompt for Visual Studio, navigate to the folder itself, and then
run this command:

g++ -std=c++17 -Wall -Wextra -pedantic Habach_test.cpp -o Habach_test.exe
.\Habach_test.exe


2. Pierce_test.cpp

-Open a Developer Command Prompt for Visual Studio, navigate to the folder itself, and then
run this command:

g++ -std=c++17 -Wall -Wextra -pedantic Pierce_test.cpp -o Pierce_test.exe
.\Pierce_test.exe
